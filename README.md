# ozon-market-agent

Агент аналитики для продавца на Ozon. Собирает данные из Seller API и ручных
выгрузок кабинета и строит Excel-отчёт: сколько реально зарабатывает каждый
артикул после комиссии, логистики, эквайринга, продвижения, себестоимости и налога.

## Что в отчёте

- **Юнит-экономика** — на штуку и за период по каждому offer_id и каналу (FBO/FBS):
  выручка, комиссия, логистика (в т.ч. возвратов), прочие услуги с расшифровкой,
  прибыль и маржа. Себестоимость списывается только с выкупленных штук.
- **Возвраты** — детально по выгрузке «Возвраты FBS и FBO».
- **Продажи по дням**, **остатки FBO/FBS** с прогнозом «на сколько дней хватит».
- **Промо «Звёздные товары»**, **логистика по регионам** (кластеры доставки),
  **здоровье карточек**.
- Опционально — сравнение прибыли на штуку с Яндекс Маркетом, если рядом лежит
  отчёт yandex-market-agent-public (соседний проект того же автора).

## Откуда деньги

С 09.2026 Ozon отключил `/v3/finance/transaction/*` — замены с разбивкой услуг по
SKU в API нет. Поэтому агент гибридный:

1. **«Отчёт по начислениям»** из кабинета (Финансы → Начисления → Скачать) —
   полная экономика по SKU. Скачать в папку загрузок перед запуском, агент найдёт
   самый свежий файл по маске.
2. **Отчёт о реализации** (`/v2/finance/realization`, только закрытые месяцы) —
   продажи и комиссия по API. Продажи, которых ещё нет в выгрузке, показываются
   жёлтыми строками «API»: без логистики и услуг, т.е. оценка сверху.

## Установка

```bash
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                        # Client-Id и Api-Key из кабинета
cp cost_prices.example.py cost_prices.py    # закупочные цены по offer_id
```

## Запуск

```bash
./run_agent.sh --days 30       # отчёт за последние 30 дней
python3 run_via_en0.py 30      # то же в обход VPN на macOS (привязка к en0)
```

Расписание на macOS — шаблон `launchd/ozon-analytics.plist.example`.
